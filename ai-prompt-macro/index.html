Microsoft Edge extension · Beta

AI Prompt Macro

ChatGPT Webに、あらかじめ決めたプロンプトを繰り返し送ったり、複数の指示を順番に実行したりできる開発支援ツールです。

現在: Microsoft Edge Add-onsでHidden配布版を審査中です。審査完了後、このページにStoreリンクを追加します。

繰り返し実行

同じPromptを最大50回まで有限回数で自動実行できます。

Flow

複数のPromptや待機を組み合わせ、A → B → Cのような手順を作れます。

Pause / Resume / Stop

長時間実行の途中でも、一時停止・再開・停止ができます。

APIキー不要

普段使っているChatGPT Webを利用します。AI Prompt Macro独自のAPI従量課金はありません。

安全側に停止

送信先や送信状態を確認できない場合は、推測して続行せず停止します。

Output-Blind

ChatGPTのassistant回答本文を使って次の送信内容を決める仕組みではありません。

こんな使い方

「現在の実装をレビューして、最も重要な改善を1つ行ってください」のような指示を繰り返し、レビュー → 改善 → 再レビューを同じチャットで続ける、といった使い方を想定しています。

対応範囲

Microsoft Edge Desktop / ChatGPT Web（chatgpt.com）。モバイル、Claude / Gemini Webの自動操作、CAPTCHAや利用上限の回避には対応していません。

AI Prompt MacroはOpenAIまたはChatGPTの公式製品ではなく、OpenAIによる提供・承認を示すものではありません。
