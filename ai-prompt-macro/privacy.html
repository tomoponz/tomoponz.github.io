AI Prompt Macro — Privacy Policy

Last updated: August 24, 2026
Publisher: tomoponz

AI Prompt Macro is a Microsoft Edge browser extension that runs finite, user-defined prompt workflows in ChatGPT Web.

1. Core privacy design

AI Prompt Macro is designed to be output-blind. It does not intentionally access, store, parse, export, transmit to the publisher, or use the body text of ChatGPT assistant responses to decide what to do next.

Because the extension runs a content script on chatgpt.com, output-blindness is an implementation constraint rather than a browser-enforced capability boundary.

2. Information handled locally

To provide its features, AI Prompt Macro may handle locally:

  • prompts and Flow source written by the user;
  • Flow Library metadata and preferences;
  • selected browser tab identifiers;
  • URL-based conversation identity used for safety checks;
  • bounded Run, cursor, outbox, timing, and schedule state;
  • prompt hashes and delivery state used to reduce unsafe re-sends;
  • optional Keep Awake preference;
  • bounded diagnostic event types and timestamps; and
  • session-scoped display aliases for tabs.

This information is stored in browser extension storage as needed for the requested features and safety behavior.

3. ChatGPT page access

AI Prompt Macro operates only on https://chatgpt.com/*.

The extension uses bounded page surfaces needed for its function, including the prompt composer, Send and generation controls, bounded login/usage/service/blocker control state, and the page URL and conversation identity used to confirm the intended target.

It is not designed to scrape or export ChatGPT conversations.

4. Network activity and third parties

AI Prompt Macro has no publisher-operated backend, analytics service, telemetry endpoint, or remote logging service.

When the user starts or resumes a workflow, AI Prompt Macro places the user's prompt into ChatGPT Web and performs the user-requested Send action. The prompt is then handled by ChatGPT/OpenAI through the user's existing ChatGPT session, in the same general way as a prompt manually submitted on ChatGPT Web.

This ChatGPT submission is a user-directed part of the extension's core function. AI Prompt Macro does not send the prompt to a tomoponz-operated service.

AI Prompt Macro does not collect the user's ChatGPT password, authentication cookies, tokens, or browser profile for the publisher.

ChatGPT/OpenAI is a third-party service with its own terms and privacy practices. AI Prompt Macro is not affiliated with or endorsed by OpenAI.

5. No publisher telemetry or sale of data

AI Prompt Macro does not have a publisher service that receives user workflows, assistant output, analytics, or usage telemetry.

The publisher does not sell user workflow data or assistant response data.

6. User controls

Users control what AI Prompt Macro sends to ChatGPT by choosing the prompt or workflow and explicitly starting or resuming a Run. Users may pause or stop an active Run, disable optional Keep Awake, edit or delete saved Flow Library items, remove the extension, or use Microsoft Edge controls to clear extension/site data where applicable.

AI Prompt Macro does not provide the publisher with a remote account or publisher-side database from which local workflows can be viewed or retrieved.

7. Permissions

  • storage — local workflows, settings, and bounded Run/outbox/diagnostic state;
  • sidePanel — extension user interface;
  • alarms — bounded local wait/schedule behavior;
  • scripting — bounded reattachment of packaged local content scripts to the explicitly selected chatgpt.com tab when needed;
  • power — optional Keep Awake while a workflow is actively running; and
  • host access to https://chatgpt.com/* — required to perform the user-requested ChatGPT Web workflow and verify the intended target.

The current design does not request tabs, history, cookies, webRequest, or <all_urls> permissions.

8. Retention

AI Prompt Macro does not maintain a publisher-side user database. Locally stored extension data remains in the user's browser until it is changed, deleted through the extension or browser, or removed with the extension/browser profile according to browser behavior.

9. Changes

This policy may be updated when AI Prompt Macro's data handling, permissions, third-party services, or supported features materially change. The policy published for a release should match the behavior of that release.
